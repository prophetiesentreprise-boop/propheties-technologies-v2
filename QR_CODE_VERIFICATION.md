# Vérification du QR code de présentation

Le QR code fourni a été intégré dans le bloc d’appel à l’action de la page « À propos ». Les contrôles visuels effectués sur écran large et mobile confirment que le code conserve un contraste élevé, une zone blanche protectrice et une taille adaptée à la numérisation.

Le visuel est enregistré dans le gestionnaire « Images du site » sous l’emplacement **À propos · QR code**. Son remplacement ultérieur ne nécessite aucune modification de code.
